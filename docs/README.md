## 📦 Inhalt

- **Notentisch.exe** – Standalone-Viewer für die Notentafel (board.html)
- **Start-Notentisch.bat** – Schnellstart für Notendarstellung
- **Dokumentation** – Installation und Anleitung

## 🚀 Schnellstart

### 1. Extrahieren
Entpacke die ZIP-Datei in einen beliebigen Ordner, z.B. `C:\Notentisch`

### 2. Starten
Doppelklick auf:
- **Start-Notentisch.bat** → Öffnet Noten im Browser

## 📖 Verwendung

### Notendarstellung (Notentisch.exe)
```
Start-Notentisch.bat
  ↓
Browser öffnet http://127.0.0.1:8000
  ↓
Noten nach Quadranten durchsuchen und ansehen
```

## ⚙️ Anforderungen

- **Windows 7** oder später
- **Browser** (Edge/Chrome/Firefox)

## ❓ Häufig gefragt

**F: Läuft es auf meinem Tablet/Handy?**  
A: Nein, nur Windows. Mit Remote Desktop kannst du dich vom Tablet aus verbinden.

**F: Wo speichert es die Noten?**  
A: Im Notentisch-Projektverzeichnis. Externe PDFs können über "Blätter"-Verzeichnis verlinkt werden.

## 🔧 Troubleshooting

| Problem | Lösung |
|---------|--------|
| Notentisch.exe startet nicht | Windows Defender Check, ggf. Firewall erlauben |
| Browser öffnet nicht automatisch | Manuell öffnen: `http://127.0.0.1:8000` |
| Port 8000 bereits in Verwendung | Andere App nutzt Port, anders konfigurieren |
