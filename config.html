Bedeutung der Werte
  • PDF-Schärfe Faktor: 1.0 = normal, höher = schärfer.
  • Papierfärbung in %: 0 = keine Tönung, 5 = deutlich sichtbar.
  • Blatt-Tönung Stärke: Feinregler von dezent bis kräftig.
  • Papierfarbe: Farbton der Tönung über den Noten.
  • Layout 2:3: Center größer, Stapel schmaler.
