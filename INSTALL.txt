===========================================
   DIGITALER NOTENTISCH - INSTALLATION
===========================================

SCHNELLSTART
------------
1. Projektordner auf neuen Windows-Rechner kopieren
2. Doppelklick auf "Notentisch.bat"
3. Browser oeffnet: http://localhost:8000/board.html

===========================================
ERSTINSTALLATION - SCHRITT FUER SCHRITT
===========================================

SCHRITT 1: VORAUSSETZUNGEN
--------------------------
- Windows 10/11
- Python 3 installiert
- Bei Python-Installation: "Add Python to PATH" aktivieren

SCHRITT 2: PROJEKT KOPIEREN
---------------------------
Kompletten Ordner "Projekt notentisch" kopieren.
Wichtig sind u.a.:
- board.html
- functions.js
- filehandling.js
- Notentisch.bat
- extract_cards.ps1
- Cards_Export\
- Blaetter\

SCHRITT 3: PDF-ORDNER PRUEFEN
-----------------------------
Die App erwartet PDFs unter "Blaetter\".

Falls "Blaetter" auf dem Zielrechner nicht funktioniert (z.B. alte Junction):
1. PowerShell als Administrator oeffnen
2. In den Projektordner wechseln
3. Junction neu setzen:

   cmd /c mklink /J "Blätter" "D:\Pfad\zu\deinen\PDFs"

SCHRITT 4: APP STARTEN
----------------------
Variante A (empfohlen):
- Doppelklick auf "Notentisch.bat"

Variante B (manuell):
- PowerShell im Projektordner oeffnen
- python -m http.server 8000
- Browser: http://localhost:8000/board.html

SCHRITT 5: XML LADEN
--------------------
1. In der App auf "LADEN" klicken
2. XML-Datei auswaehlen
3. Karten erscheinen in den Quadranten

===========================================
OPTIONAL: KARTENBILDER ERZEUGEN
===========================================

Befehl im Projektordner:

.\extract_cards.ps1

Das Skript nutzt bevorzugt:
- .\poppler-25.12.0\Library\bin\pdfimages.exe

Wenn dieser Pfad nicht existiert, wird pdfimages.exe aus PATH verwendet.

===========================================
## Start auf einem anderen Windows-System
===========================================

 so gehts: .\setup_notentisch.ps1

  Das Skript erledigt für dich:

  Prüfung auf Python 3 und Poppler (pdfimages.exe)
  Anlage des „Blätter“-Ordners bzw. Erstellen einer Junction zu deinen PDFs
  Anlage des „Cards_Export“-Ordners
  Prüfung, ob der Standard-Port 8000 frei ist (ggf. Alternativport)
  Start des lokalen Servers und Öffnen der App im Browser (optional)
  Du kannst das Skript jederzeit erneut ausführen, falls du die Ordnerstruktur oder Verknüpfungen anpassen möchtest.
  
===========================================
PROBLEMLOESUNG
===========================================

PROBLEM: "Python wurde nicht gefunden"
LOESUNG:
- Python 3 installieren
- "Add Python to PATH" aktivieren
- Neues Terminal oeffnen

PROBLEM: Browser oeffnet nicht
LOESUNG:
- URL manuell oeffnen: http://localhost:8000/board.html

PROBLEM: PDF wird nicht geladen
LOESUNG:
- Pruefen, ob Server laeuft
- Pruefen, ob PDFs unter Blaetter\ erreichbar sind
- Falls noetig, Junction neu erstellen (siehe SCHRITT 3)

PROBLEM: Keine Kartenbilder
LOESUNG:
- .\extract_cards.ps1 ausfuehren
- Poppler-Pfad pruefen (siehe OPTIONAL)
